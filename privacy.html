Privacy Policy

MuteBar for macOS — effective November 16, 2026

The short version: MuteBar collects nothing, tracks nothing, and has no network access. Everything it does happens on your Mac.

What MuteBar does

MuteBar is a menu-bar utility that lets you mute individual applications. To do this it uses Apple's public Core Audio process tap API (AudioHardwareCreateProcessTap) to attach a private tap to the audio produced by apps you select, and sets the tap's mute behaviour so that the selected app's output is silenced while the tap remains active.

Data collection

MuteBar collects no personal data. It has no analytics, no advertising, no crash reporting, no telemetry, and no third-party SDKs. The app contains no networking code and is unable to send data anywhere. Nothing you use MuteBar with is transmitted off your Mac.

No account is required, and no information is shared with the developer or with anyone else.

Audio handling

Audio buffers delivered by a Core Audio tap are discarded immediately in memory. MuteBar does not record, store, write, transmit, or analyse any audio. It never requests microphone input, and it does not read audio from input devices. The Audio Input capability declared by the app exists because macOS classifies Core Audio process taps under audio input APIs; the captured data is used only to keep the tap active for muting and is dropped at once.

What is stored on your Mac

  • Mute preferences — the bundle identifiers of apps you have muted, kept in the standard macOS preferences system (NSUserDefaults) for your user account only.
  • Log file — a short local diagnostic log at ~/Library/Logs/MuteBar.log (inside the app's container when sandboxed). It contains app names and status messages only, never audio. You can read or delete it at any time.

Both are deleted when you uninstall the app.

Permissions

MuteBar runs in the macOS App Sandbox. It requests no Screen Recording permission, no Accessibility permission, and no Full Disk Access. On some macOS versions the system may show a one-time prompt related to audio input; declining it does not affect any other part of the app.

Login items

If you turn on “Start at Login”, macOS registers MuteBar as a login item using the standard system mechanism (SMAppService). This registration is visible and revocable in System Settings › General › Login Items. MuteBar never registers anything else.

Children

MuteBar is a general utility and is not directed at children under 13.

Changes to this policy

If this policy changes, the updated version will ship with a new release of the app and the date above will be updated. Material changes will be noted in the app's release notes.
